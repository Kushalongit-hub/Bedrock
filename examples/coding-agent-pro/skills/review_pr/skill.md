# Review Pull Request Skill

Review a pull request for correctness, style, and test coverage.

## Requirements
- fs.read
- code.search
- git.diff
- shell.execute

## Workflow
1. Fetch PR diff
2. Read changed files
3. Check for test coverage
4. Verify style guidelines
5. Run static analysis if available
6. Summarize findings

## Success Criteria
- All review comments are actionable
- No critical issues missed
